# POS Multi-Trade problem brief

Status: draft — evidence collection in progress

## Intended customer

台灣微型店家、連鎖加盟主，以及同一經營者同時管理餐飲、零售或服務型業務的店家。

## Job to be done

在尖峰營運時，店員可以快速完成收銀、查看商品／庫存與訂單；店主可以用同一套 local-first 工具切換業態，而不必為不同店型維護多套流程。

## Problem hypotheses

1. 小型店家需要低導入成本、低學習成本的收銀與商品管理工具。
2. 店型切換、商品／庫存維護、離線使用與資料可攜性是比「更多報表」更接近日常工作的需求。
3. POS 選型常受到前台速度、斷網可用性、出單／支付整合、費用透明度與導入訓練影響。

## What is not yet proven

- 店家是否真的需要在同一 workspace 切換三種 industry profile。
- local-first 與 JSON portability 是否足以驅動轉換。
- 店家願意支付的價格與真正的 committed demand。
